# Attribution and terms

This repository contains the `plugin_chatwidget` extension developed by Vedesh Reddy,
plus layout overlays derived from Salesforce Storefront Reference Architecture (SFRA).
It is an SFRA extension, not an official Salesforce product.

The following overlays are adapted from SFRA templates to include the widget:

- `common/layout/page.isml`
- `common/layout/checkout.isml`
- `common/layout/pdStorePage.isml`
- `common/layout/pdComponentPage.isml`
